# 萤火协作平台发布记录

## v2.3.0（2026-06-15）

### 新增
- 任务模块支持 CSV 批量导入。
- 消息中心新增 @提及提醒。
- 项目仪表盘支持自定义图表。

### 修复
- 修复附件上传大小限制问题。此前限制为 10 MB，现已调整为 50 MB。
- 修复 Safari 17 下甘特图拖拽失效的问题。
- 修复通知邮件中文字符乱码。

### 变更
- 默认分页大小从 10 条改为 20 条。

## v2.2.0（2026-04-20）

### 新增
- 代码审查模块支持行内评论。
- 流水线支持 GitLab CI 集成。

### 修复
- 修复大文件下载超时导致任务状态未更新。
- 修复搜索索引在凌晨 2:00 重建期间不可用。

### 变更
- API 速率限制从每小时 500 次调整为 1000 次。

## v2.1.0（2026-02-10）

### 新增
- 移动端支持消息推送通知。
- 文档模块支持全文搜索。

### 修复
- 修复任务看板拖拽排序后未保存的问题。
- 修复 iOS Safari 上文件上传按钮无响应。

## v2.0.0（2025-12-01）

### 新增
- 全新的项目仪表盘，支持任务、流水线和缺陷概览。
- 多租户架构，支持团队间数据隔离。
- REST API v1 正式发布。

### 修复
- 修复高并发下任务创建偶发死锁。
- 修复统计数据缓存未及时刷新。

## v1.0.0（2025-08-01）

- 初始版本发布，包含任务管理、文档共享和即时通讯三个模块。
